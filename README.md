# Leonida Bird Log

A fan-made birdwatching checklist for GTA 6. Tick off the 62 bird species of Leonida, count your sightings, and save a share card for social media.

Live at **https://leonidabirdlog.com**

- Everything lives in a single file, `index.html`, with no build step.
- Each player's progress is saved in their own browser (localStorage).
- Hosted on GitHub Pages; `CNAME` points it at the custom domain.

The bird list is unofficial. Rockstar hasn't published the full list, so it's based on common Florida birds for now and will be updated as players log the real ones.
